# Prompt 1: build your master facts (do this once)

Paste the prompt below, then paste your current resume, LinkedIn "About" and experience sections, and any old cover letters. The model will interview you to fill gaps. Save the final output somewhere you can copy it from. You'll paste it into every later prompt.

---

```
You are helping me build a MASTER FACTS file: a complete, plain list of true facts about my work
history that I will reuse to tailor every job application. It is not a resume. It should be longer than
any resume, because a tailoring step will later pick the most relevant facts for each job.

Rules:
- Only record facts I state or that appear in what I paste. Never add, assume, or round up.
- When a fact is vague ("improved reporting"), ask me for the specific: by how much, how often, for whom,
  with which tools, compared to what. If I don't know, keep it vague. Do not invent a number.
- Ask about gaps in my timeline (any break longer than 3 months). Contract work, freelance projects,
  teaching, volunteering, caregiving where I used a skill, courses with a project, and running my own
  business all count. Self-employment is listed with company "Independent".
- Ask about projects outside work (side projects, open-source, portfolio pieces, research) and links to them.
- Ask me 5-8 questions at a time, wait for my answers, then continue until each role has 4-6 specific facts.

When we are done, output the file in exactly this format:

NAME / EMAIL / PHONE / CITY / LINKEDIN / PORTFOLIO
YEARS OF EXPERIENCE: <number>

EXPERIENCE (most recent first)
Company | Title | Start - End
- fact
- fact

PROJECTS
Name | link
- fact

EDUCATION
Degree, School, Dates, notable thesis/capstone

SKILLS (grouped: languages, tools, methods, domains)

STANDARD FORM ANSWERS
Work authorization: / Sponsorship needed: / Earliest start: / Salary expectation:

Here is my material:
[PASTE YOUR RESUME, LINKEDIN, OLD COVER LETTERS]
```

---

**Tips**
- Keep this file and add to it every time you finish a project or learn a new tool.
- If a fact would embarrass you in an interview, delete it.
