# Step 5: format and export so an ATS reads it

Applicant tracking systems (ATS) turn your file into text before a person sees it. Fancy layouts scramble that text. This is the checklist the agent applies to every file it makes.

## Layout
- [ ] **One column.** No sidebars, text boxes, or tables for layout.
- [ ] **Nothing important in the header or footer.** Put your name and contact line in the body.
- [ ] **Standard section headings:** Summary, Experience, Projects, Education, Skills.
- [ ] **A common font:** Georgia, Calibri, Arial, or Times New Roman, 10–11.5 pt for body text.
- [ ] **No photos, icons, skill bars, or charts.**
- [ ] **Dates as "Jun 2021 - Present"** with a plain hyphen, on the same line as the employer.
- [ ] **Plain bullets** from the bullet-list button, not special symbols you typed.
- [ ] **No em dashes or curly "smart" quotes** pasted from a chat window. Find and replace `—` and `–` with a comma or a plain hyphen.

## Export
- [ ] **Save both a PDF and a .docx.** Some portals parse one better than the other. Upload the PDF unless the portal asks for Word.
- [ ] **The PDF must contain real text.** Open it and try to select a sentence. If you can't, it's an image, and the ATS sees nothing. Never "print to image" or scan.
- [ ] **File name:** `First_Last_Resume.pdf` and `First_Last_Cover_Letter.pdf`.

## Clean the file details (metadata)

Files carry hidden details: author, the tool that made them, and sometimes the original template's name and dates. Make sure they only say you.

**Microsoft Word (Windows):** File → Info → **Check for Issues → Inspect Document** → Remove All for "Document Properties and Personal Information". Then File → Info → Properties → set **Author** to your name. Then export to PDF.

**Microsoft Word (Mac):** Word → Preferences → Security & Privacy → check **Remove personal information from this file on save**. Then set File → Properties → Author to your name, and save as PDF.

**Google Docs:** start from a blank document, not a template. Name the document `First Last Resume`, since that becomes the PDF title. Then File → Download → PDF.

**Mac Pages:** File → Export To → PDF, then check the PDF as described below.

**Check any PDF:** open it in a browser or Preview and look at Document Properties (Preview: Tools → Show Inspector). Title and Author should be you, and nothing should name a template, a website, or an AI tool.

## Final read
- [ ] Every number and tool on the page passed [Prompt 4](4_fact_check.md).
- [ ] You read the cover letter out loud and it sounds like you.
- [ ] The company name and role title are correct, in the letter and in the file name if you included them.
